# Invoxy — SaaS Landing Page (Demo Project)

A high-conversion landing page for a smart-invoicing SaaS product.
Designed & built as a **single self-contained HTML file** — no frameworks, no build step, no dependencies. Fonts are embedded; everything works offline.

**→ Open `index.html` in any browser. That's the whole website.**

## What's inside

- 🎯 Conversion-focused structure: outcome-first hero → social proof → features → ROI calculator → pricing → FAQ → CTA
- 🖥️ Product dashboard mockup drawn in pure CSS/SVG (cash-flow chart, invoice list, live-looking UI)
- 🧮 Interactive ROI calculator with animated results
- 🌗 Light / dark theme (remembers the visitor's choice)
- 💳 Monthly / yearly pricing toggle
- ❓ FAQ accordion, lead-capture form with validation
- 📱 Fully responsive: 320 px → 4K, tested with zero console errors

## Tech

- Pure HTML + CSS + vanilla JavaScript (no libraries)
- Embedded WOFF2 fonts (Inter, Space Grotesk)
- Accessible: semantic markup, ARIA attributes, keyboard-friendly
- Lighthouse-friendly: one file, ~220 KB total, loads instantly

## Notes

This is a **portfolio demo** — Invoxy is a fictional product. All data, clients and reviews are illustrative.
